# Security

Call my agent! sits between an engineer's repository and another party's agent, so security reports are very welcome.

**Please don't open a public issue for a vulnerability.** Report it privately through GitHub: **Security → Report a vulnerability** on this repository. You'll get a reply within a few days.

Useful to include: what an attacker controls (a peer agent, an invite, the relay, a file in the repo), what they can achieve, and a test or steps that reproduce it.

The threat model is in [docs/design/proposal.md](docs/design/proposal.md#security-and-trust-model) and the enforced rules in [docs/design/implementation-spec.md](docs/design/implementation-spec.md).
